# Vision audit — checklist (owner judgment, agent collation)

Walk `docs/VISION.md` top to bottom. For each item record **hold / amend / retire** + one
line of evidence from the pack. Amend/retire → ADR. Hold → listed in the review's no-change
ADR.

- **The dream**: "in one hand see what's happening, in the other create your own work" —
  still the frame? What shipped this quarter served which hand?
- **Three circles** (Operate / Create / Join): still the right segmentation? Any signal from
  triage that a fourth exists or one is empty?
- **Membership by invitation** (Join → member): still the right growth model, or is the
  request → approve door due earlier than Phase 6?
- **Principle 1 — community as creators**: any evidence members want to *create* vs consume?
  (This is the core bet; contradicting evidence is the queue-jumper.)
- **Principle 2 — everything is a module**: did the quarter's work plug in, or bend the core?
- **Principle 3 — one login, roles decide**: any pressure toward per-user overrides or a
  second identity? (Decided against 2026-07-20; re-ask, don't re-litigate silently.)
- **Principle 4 — public by default**: is anything marked internal by habit rather than
  decision?
- **Principle 5 — bilingual + mobile-first**: retrofits this quarter? (Each one is a
  process failure to name.)
- **Principle 6 — real numbers, tightly guarded**: any money visible wider than intended?
- **Principle 7 — evolution not revolution**: any cut-over before parity?
- **"Where we are today"**: rewrite the paragraph to be true (this is always an amendment).
- **Quarter bets**: list the block's bets; validated / invalidated / no signal, per triage.
