# briefs/ — one prompt per reel

Written by the `new-video` skill from the owner's answers, one file per creative
(`<slug>.md`, from `.claude/skills/new-video/brief-template.md`). A brief is the complete,
self-contained prompt a build session follows: spec, safe zone, type minimums, numbered shots with
seconds and the exact Hebrew and Arabic copy, assets by path, motion from the kit, acceptance
checks, the render matrix. Approved briefs are committed with the reel; the plan's publish log
(docs/plans/video-pipeline.md) says which were posted and when.
